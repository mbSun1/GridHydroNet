# DistHydroNet 分布式混合水文模型说明

> 文档用途：本文件依据当前 `disthybridcore` 源代码整理，可作为论文 Methods、模型补充材料和代码复现实验说明的基础。文中公式描述的是当前实际运行实现，而不是概念性设计草案。

## 1. 模型定位与总体结构

当前分布式混合模型可表述为一个“神经网络参数区域化 + 分布式 HBV92 产流 + 全栅格 D8 非线性动态汇流”的端到端可微分水文模型。推荐在论文中使用以下名称：

**神经参数化的可微分分布式 HBV92–D8 动态汇流模型**

模型利用训练期的多年栅格气象背景和静态地形属性，为每个有效栅格生成一套空间异质、时间不变的 HBV92 参数；随后在逐日尺度上计算各栅格的降雪、融雪、土壤蓄水、蒸散发、壤中流与地下径流；最后将各栅格的产流量转换为体积流量，并沿完整的 D8 有向无环图传播到内部监督站和流域出口。

```text
训练期多年 P/T/PET 背景 + 四通道静态地形
                         │
                         ▼
      共享权重的逐栅格参数编码器
        BiGRU / TCN / Patch Transformer
                         │
                         ▼
       12 个有物理边界的 HBV92 参数场
                         │
逐日 P/T/PET ──► 栅格 HBV92 产流与状态更新
                         │
                  Q0 + Q1 + Q2 [mm d⁻¹]
                         │
             按实际栅格面积换算为 [m³ s⁻¹]
                         │
                         ▼
   坡面/河道参数有区别的全栅格 D8 隐式动态汇流
                         │
                         ▼
          内部站与出口站逐日流量 [m³ s⁻¹]
                         │
                         ▼
   多站点等权、面积归一化的组合 RMSE 监督损失
```

当前运行版本只有单分量 HBV92，没有 HBV96 分支，也没有 Gamma 单位线、Muskingum 河道路由、有效河段分割或多个并行 HBV 分量。`Q0`、`Q1` 和 `Q2` 在进入空间汇流前相加，因此三种径流分量目前不使用不同的空间传播速度。

## 3. 数据输入与空间预处理

### 3.1 动态输入

模型只使用三类逐日栅格气象强迫：降水 $P$、2 m 气温 $T$ 和潜在蒸散发 $E_p$。P/PET 单位为 mm d$^{-1}$，T 单位为 °C。HBV92 水量平衡直接接收原始物理量；标准化气象背景仅用于神经参数编码器。

### 3.2 流域掩膜与实际栅格面积

流域边界与模型网格求精确相交，得到栅格流域覆盖率 $f_i\in(0,1]$。若正方形完整栅格面积为 $A_{0}$，则实际参与水量换算的面积为

\[
A_i=f_iA_0.
\]

因此边界栅格不会被错误地按完整栅格面积计算，流域出口的累计 D8 面积应与全流域实际面积闭合。

### 3.3 四通道静态地形特征

参数编码器使用以下四个逐栅格静态属性：

\[
\mathbf{s}_i=[z_i,\; |\nabla z_i|,\; \partial z_i/\partial x,\; \partial z_i/\partial y].
\]

其中高程单位为 m，坡度模长及两个方向梯度为 m m$^{-1}$。这些特征在最终模型网格的原始 DEM 上计算，而不是在 30 m 原始 DSM 或填洼后的 DEM 上计算。每个通道采用中位数和 MAD 进行稳健标准化：

\[
\widetilde{x}=\operatorname{clip}\left(
\frac{x-\operatorname{median}(x)}
{1.4826\,\max[\operatorname{median}(|x-\operatorname{median}(x)|),10^{-6}]},
-8,8\right).
\]

### 3.4 DEM 水文校正与 D8 拓扑

在指定出口约束下，代码使用 priority-flood 对 DEM 进行水文校正。每个有效栅格在 8 邻域中选择最大正向坡降方向作为唯一 D8 下游；若填洼区没有严格下降邻格，则使用 priority-flood 记录的父节点。正交链路长度为网格边长，对角链路长度为其 $\sqrt{2}$ 倍。只有总出口栅格自指向，其他有效栅格均指向另一个有效栅格。

沿 D8 图按上游至下游拓扑顺序累积实际面积：

\[
A_i^{\uparrow}=A_i+\sum_{j\in\mathcal U(i)}A_j^{\uparrow},
\]

其中 $\mathcal U(i)$ 为直接汇入栅格 $i$ 的上游栅格集合。河道栅格由累计面积阈值确定：

\[
c_i=\mathbb I(A_i^{\uparrow}\ge A_{\mathrm{thr}}),
\]

并强制出口为河道栅格。当前命令行默认 $A_{\mathrm{thr}}=20\ \mathrm{km^2}$。`routing_level` 是完整有效栅格图的计算层级，同层栅格之间没有上下游依赖，可并行求解；`stream_order` 是抽取河道栅格上的 Strahler 等级，两者不能混用。

### 3.5 测站与 D8 栅格映射

出口站固定映射到唯一 D8 出口。内部测站根据投影距离、官方控制面积和声明的上下游关系映射到未占用的河道格，并检查映射后的 D8 下游关系。每个站点的模型控制面积取其映射栅格的 $A_i^{\uparrow}$。内部站只读取该栅格处的流量，不从河网中抽走水量，因此流量仍继续传播至下游。

## 4. 神经网络如何学习空间 HBV92 参数

### 4.1 参数学习的对象

深度学习模块不是直接预测逐日流量，而是学习从“训练期气候背景 + 静态地形”到 HBV92 参数场的映射：

\[
\boldsymbol\theta_i=\mathcal B\left[h_{\psi}(\mathbf X_i,\mathbf s_i)\right],
\]

其中 $\mathbf X_i\in\mathbb R^{L\times3}$ 为栅格 $i$ 的训练期气象序列，$h_{\psi}$ 为共享权重的 BiGRU、TCN 或 Patch Transformer，$\mathcal B$ 为带物理边界的参数头，$\boldsymbol\theta_i$ 包含 12 个 HBV92 参数。

同一个编码器和参数头用于所有有效栅格，因此模型不是为每个栅格设置 12 个相互独立、无结构的自由参数，而是通过共享网络实现空间区域化。栅格间的参数差异来自各栅格不同的气候背景和地形特征。

HBV92 参数没有逐栅格“真值”标签，编码器完全依靠各监督站的流量误差进行间接学习。当前编码器逐格处理序列，不在参数生成阶段使用空间卷积或邻格注意力；不同栅格首先通过共享权重获得参数，栅格之间的显式水文联系随后由 D8 汇流建立。多站点损失则从不同空间位置共同约束这些共享权重。

### 4.2 固定训练期气候背景

参数背景只从预先声明的训练期构建，不读取测试期气象。默认 `block_days=1`，每一步包含日降水、日平均气温和日 PET。BiGRU 允许采用更大的时间块，此时降水和 PET 被换算为块内平均日量，气温取块平均；当前 TCN 和 Patch Transformer 配置强制使用逐日背景，即 `block_days=1`。

降水首先进行长尾压缩：

\[
x_{P,i,t}=\log_{10}(\sqrt{\max(P_{i,t},0)}+0.1).
\]

气温和 PET 保持恒等变换。随后，对每个通道使用训练期全部有效栅格和全部日期的共享均值、标准差进行 Z-score 标准化：

\[
\widehat{x}_{k,i,t}=\frac{x_{k,i,t}-\mu_k}{\max(\sigma_k,10^{-6})}.
\]

流域外像元置零。该标准化序列只服务于参数区域化；HBV92 仍使用原始 $P,T,E_p$。

### 4.3 默认 BiGRU 参数编码器

对每个有效栅格，将四维静态地形向量复制到每个时间步，与三维气候特征拼接：

\[
\mathbf v_{i,t}=[\widehat P_{i,t},\widehat T_{i,t},\widehat E_{p,i,t},\mathbf s_i]\in\mathbb R^7.
\]

默认结构为：

```text
7 维输入 → Linear(7,16) → ReLU
→ 1 层双向 GRU，单向隐藏维 16
→ 全序列时间均值（32 维）和总体标准差（32 维）
→ 再拼接 4 维地形 → 68 维逐栅格表征
```

即

\[
\mathbf e_i=[\operatorname{mean}_t(\mathbf h_{i,t}),
\operatorname{std}_t(\mathbf h_{i,t}),\mathbf s_i].
\]

BiGRU 在训练期历史背景内部双向编码，但得到的是一套静态参数场；它不读取测试期数据，也不执行逐日未来径流预测，因此这里的“双向”不构成测试期未来信息泄漏。

### 4.4 可选 TCN 参数编码器

TCN 同样将 3 个气候通道与 4 个静态地形通道逐日拼接。首先用 $1\times1$ 卷积映射到 32 个时间通道，再经过 11 个残差因果卷积块。卷积核为 3，膨胀率为 $1,2,4,\ldots,1024$。所有卷积只在左侧填充，因而单个时刻的中间表示不使用其后的输入。每个块使用 SiLU、dropout=0.1 和残差连接。感受野为

\[
R=1+(3-1)\sum_{l=0}^{10}2^l=4095\ \text{days}.
\]

最终以全序列均值和标准差汇总，并再次拼接地形特征。因果性针对中间特征序列；最终参数是对完整训练期背景的静态汇总。

### 4.5 可选 Patch Transformer 参数编码器

Patch Transformer 对三通道气候序列执行 30 d 的无重叠卷积切片，卷积核和步长均为 30 d；不足一个完整 patch 的尾段用标准化零值右填充。每个 token 宽度为 64，叠加正弦位置编码和线性地形嵌入后进入 2 层、4 头 Transformer Encoder；前馈层宽度为 128，激活为 GELU，dropout=0.1，采用 norm-first 结构。

编码后的 token 按时间求均值和总体标准差，再拼接原始四维地形特征。该 Transformer 是训练期气候背景编码器，不是带未来预报输入的序列到序列径流预测器。

### 4.6 共享参数头与物理边界

三类编码器共用相同形式的参数头：

```text
逐栅格时序表征 + 地形
→ LayerNorm → Linear(F,16) → SiLU → Linear(16,12)
→ Sigmoid 物理边界映射
```

若第 $p$ 个网络原始输出为 $r_{i,p}$，参数上下界为 $(l_p,u_p)$，则

\[
\theta_{i,p}=l_p+(u_p-l_p)\,\sigma(r_{i,p}).
\]

| 参数 | 作用 | 范围 | 单位 |
|---|---|---:|---|
| `beta` | 土壤湿润度–补给非线性指数 | 1–6 | 1 |
| `fc` | 最大土壤蓄水容量 | 50–1000 | mm |
| `k0` | 超过阈值部分的快速退水系数 | 0.05–0.9 | d⁻¹ |
| `k1` | 上层慢速退水系数 | 0.01–0.5 | d⁻¹ |
| `k2` | 下层基流退水系数 | 0.001–0.2 | d⁻¹ |
| `lp` | 蒸散开始受限的相对土壤湿度 | 0.2–1 | 1 |
| `perc` | 上层向下层最大渗漏量 | 0–10 | mm d⁻¹ |
| `uzl` | 快速径流启动的上层蓄水阈值 | 0–100 | mm |
| `tt` | 雨雪分界温度 | -2.5–2.5 | °C |
| `cfmax` | 度日融雪因子 | 0.5–10 | mm (°C d)⁻¹ |
| `cfr` | 再冻结系数 | 0–0.1 | 1 |
| `cwh` | 积雪持液能力系数 | 0–0.2 | 1 |

这些参数在不同栅格上不同，但对一个固定检查点而言不随模拟日期变化。网络权重、参数头权重和汇流区域化系数共同由站点流量误差反向传播更新。

参数场在每个模型前向窗口内使用当前网络权重重新生成，并未作为脱离计算图的常量预先保存，因而站点损失可以持续回传至参数编码器。为控制多年逐日序列的显存占用，有效栅格默认每 256 个分块编码；训练时使用梯度检查点，以反向阶段的重复计算换取较低显存占用。这两项措施不改变参数化公式。

## 5. 可微分栅格 HBV92 产流模型

### 5.1 状态变量

每个有效栅格保存五个日末水量状态：

\[
\mathbf x_{i,t}=[SP,MW,SM,UZ,LZ]_{i,t},
\]

分别表示固态积雪、积雪液态水、土壤含水量、上层响应库和下层响应库，单位均为 mm。历史预热前五个状态均初始化为 $10^{-3}$ mm；土壤水更新后设置 $10^{-5}$ mm 的数值下限。

### 5.2 雨雪划分

\[
P^{rain}_{i,t}=P_{i,t}\,\mathbb I(T_{i,t}\ge TT_i),
\qquad
P^{snow}_{i,t}=P_{i,t}\,\mathbb I(T_{i,t}<TT_i).
\]

该硬阈值严格匹配当前参考实现。布尔比较本身不对 $TT$ 提供常规梯度，详见第 9 节。

### 5.3 积雪、融雪与再冻结

\[
SP^*_{i,t}=SP_{i,t-1}+P^{snow}_{i,t},
\]

\[
M_{i,t}=\min[\max\{CFMAX_i(T_{i,t}-TT_i),0\},SP^*_{i,t}],
\]

\[
MW^*_{i,t}=MW_{i,t-1}+M_{i,t},\qquad
SP^{**}_{i,t}=SP^*_{i,t}-M_{i,t},
\]

\[
RF_{i,t}=\min[\max\{CFR_iCFMAX_i(TT_i-T_{i,t}),0\},MW^*_{i,t}],
\]

\[
SP_{i,t}=SP^{**}_{i,t}+RF_{i,t},\qquad
MW^{**}_{i,t}=MW^*_{i,t}-RF_{i,t},
\]

\[
I^{soil}_{i,t}=\max(MW^{**}_{i,t}-CWH_iSP_{i,t},0),
\qquad
MW_{i,t}=MW^{**}_{i,t}-I^{soil}_{i,t}.
\]

### 5.4 土壤水、补给与实际蒸散发

\[
w_{i,t}=\operatorname{clip}\left[
\left(\frac{SM_{i,t-1}}{FC_i}\right)^{\beta_i},0,1
\right],
\]

\[
RCH_{i,t}=(P^{rain}_{i,t}+I^{soil}_{i,t})w_{i,t},
\]

\[
SM^*_{i,t}=SM_{i,t-1}+P^{rain}_{i,t}+I^{soil}_{i,t}-RCH_{i,t},
\]

\[
EXC_{i,t}=\max(SM^*_{i,t}-FC_i,0),\qquad
SM^{cap}_{i,t}=SM^*_{i,t}-EXC_{i,t},
\]

\[
f^E_{i,t}=\operatorname{clip}\left(\frac{SM^{cap}_{i,t}}{LP_iFC_i},0,1\right),
\]

\[
E_{a,i,t}=\min(SM^{cap}_{i,t},E_{p,i,t}f^E_{i,t}),
\qquad
SM_{i,t}=\max(SM^{cap}_{i,t}-E_{a,i,t},10^{-5}).
\]

### 5.5 上层、下层响应与三种径流分量

当前实现严格按“渗漏 → $Q_0$ → $Q_1$ → $Q_2$”的顺序更新：

\[
UZ^*_{i,t}=UZ_{i,t-1}+RCH_{i,t}+EXC_{i,t},
\]

\[
PERC_{i,t}=\min(UZ^*_{i,t},PERC_i),\qquad
UZ^{p}_{i,t}=UZ^*_{i,t}-PERC_{i,t},
\]

\[
Q_{0,i,t}=K_{0,i}\max(UZ^{p}_{i,t}-UZL_i,0),
\qquad UZ^{q0}_{i,t}=UZ^{p}_{i,t}-Q_{0,i,t},
\]

\[
Q_{1,i,t}=K_{1,i}UZ^{q0}_{i,t},\qquad
UZ_{i,t}=UZ^{q0}_{i,t}-Q_{1,i,t},
\]

\[
LZ^*_{i,t}=LZ_{i,t-1}+PERC_{i,t},
\]

\[
Q_{2,i,t}=K_{2,i}LZ^*_{i,t},\qquad
LZ_{i,t}=LZ^*_{i,t}-Q_{2,i,t}.
\]

总局地产流深为

\[
R_{i,t}=Q_{0,i,t}+Q_{1,i,t}+Q_{2,i,t}.
\]

### 5.6 产流水量平衡

每个栅格每日检查

\[
\varepsilon^{HBV}_{i,t}
=W_{i,t-1}+P_{i,t}-E_{a,i,t}-Q_{0,i,t}-Q_{1,i,t}-Q_{2,i,t}-W_{i,t},
\]

其中 $W=SP+MW+SM+UZ+LZ$。输出诊断对残差绝对值按实际栅格面积加权平均。

## 6. 从产流深到空间汇流源项

栅格产流深通过该栅格实际面积转换为体积流量：

\[
L_{i,t}=R_{i,t}\,A_i\frac{1000}{86400}.
\]

1 mm 水深作用于 1 km² 对应 $1000\ \mathrm{m^3}$，再除以 $86400\ \mathrm{s\,d^{-1}}$ 得到 m³ s$^{-1}$。局地产流不会被瞬时聚合到最近河道。每个坡面格先在自身汇流方程中接收 $L_{i,t}$，然后沿连续的 D8 下游链逐格传播。这是“全有效栅格汇流”，不是“坡面产流直接散射到河道”。

## 7. 可微分全栅格 D8 动态汇流

### 7.1 是否区分坡面栅格与河道栅格参数

**区分。** 当前模型为非河道栅格和河道栅格构造不同的 $a_i,b_i$ 参数场。

**但不使用两套独立的汇流方程。** 两类栅格都位于同一张完整 D8 图中，都由第 7.4 节的同一个隐式非线性守恒方程更新。固定河道掩膜只负责选择每个栅格采用坡面参数还是河道参数，同时也是参数区域化特征之一。

准确的论文表述是：

> 模型在统一的全栅格 D8 汇流框架内，对坡面格和河道格采用分类型的空间汇流参数场；两类栅格共享同一守恒方程与数值求解器，而非采用相互独立的坡面和河道 PDE 求解器。

### 7.2 汇流区域化特征

\[
\mathbf z_i=\operatorname{standardize}\left[
\log(1+A_i^{\uparrow}),
\log_{10}(\max(s_i,10^{-6})),
z_i^{cond},c_i
\right],
\]

其中 $s_i$ 为 D8 链路坡度，$z_i^{cond}$ 为水文校正后的高程，$c_i\in\{0,1\}$ 为河道掩膜。标准化使用全部有效栅格上的均值和总体标准差。

### 7.3 坡面/河道汇流参数场

坡面候选参数为

\[
r^{a,h}_i=\alpha_a+\mathbf z_i^\top\mathbf w_a,
\qquad
a_i^h=0.001+(50-0.001)\sigma(r^{a,h}_i),
\]

\[
r^{b,h}_i=\alpha_b+\mathbf z_i^\top\mathbf w_b,
\qquad
b_i^h=0.001+(1-0.001)\sigma(r^{b,h}_i).
\]

河道 $a$ 通过相对于同位置坡面候选值的比例进行约束：

\[
\rho_i^c=0.05+0.95\sigma(\alpha_\rho+\mathbf z_i^\top\mathbf w_\rho),
\]

\[
a_i^c=0.001+(a_i^h-0.001)\rho_i^c,
\]

因此始终有 $a_i^c\le a_i^h$。河道 $b$ 单独区域化：

\[
b_i^c=0.001+(1-0.001)\sigma(\alpha_{b,c}+\mathbf z_i^\top\mathbf w_{b,c}).
\]

最终按固定河道掩膜选择：

\[
(a_i,b_i)=
\begin{cases}
(a_i^c,b_i^c), & c_i=1,\\
(a_i^h,b_i^h), & c_i=0.
\end{cases}
\]

初始值为 $a^h=5.0$、$b^h=0.60$、河道 $a$ 比例约 0.30、$b^c=0.60$。这些截距和特征权重是直接可训练参数，不是 BiGRU/TCN/Transformer 的输出：12 个 HBV92 参数场由神经编码器生成；D8 的 $a,b$ 参数场由另一组共享的可训练区域化系数生成；两组参数通过同一个多站点流量损失联合优化。

汇流区域化一共包含 20 个共享标量：4 个截距和 4 组各含 4 个元素的特征权重。它们生成所有有效栅格的汇流参数，而不是为每个栅格独立保存两个自由率定量。

### 7.4 非线性蓄量–流量关系

\[
F_{b_i}(Q)=\left(Q^2+\epsilon^2\right)^{b_i/2}-\epsilon^{b_i},
\qquad \epsilon=10^{-4}\ \mathrm{m^3\,s^{-1}},
\]

\[
F_{b_i}'(Q)=b_iQ\left(Q^2+\epsilon^2\right)^{b_i/2-1}.
\]

栅格链路蓄量定义为

\[
S_i(Q)=a_iF_{b_i}(Q)\Delta x_i^{eff},
\qquad
\Delta x_i^{eff}=\max(\Delta x_i,1\ \mathrm m).
\]

1 m 下限主要用于 D8 距离为 0 的自指向出口。因为 $b_i$ 可变，$a_i$ 的量纲随 $b_i$ 改变，不能把 $a_i$ 简单解释为统一单位下的流速或旅行时间。对相同 $Q,b,\Delta x$，较小的 $a$ 表示较小的链路蓄量，但实际响应仍由所有变量共同决定。

若将 $Q$ 的量纲写为 $\mathrm{m^3\,s^{-1}}$，由 $S=aQ^b\Delta x$ 可得 $a$ 的形式量纲为 $\mathrm{m^{2-3b}\,s^b}$。由于 $b$ 也是空间可变参数，表中 $a$ 的数值边界主要是模型内部约束，不能脱离 $b$ 直接进行跨栅格物理比较。

### 7.5 隐式守恒方程

设第 $m$ 个子步长度为

\[
\Delta t=\frac{86400}{M}.
\]

局地产流 $L_{i,t}$ 在当天全部 $M$ 个子步内保持为同一个 m³ s$^{-1}$ 值，不再除以 $M$，因此其全天体积仍为 $86400L_{i,t}$。每个栅格满足

\[
\Delta t\,Q_i^{m+1}+S_i(Q_i^{m+1})
=\Delta t[U_i^{m+1}+L_{i,t}]+S_i(Q_i^m).
\]

代入蓄量函数并除以有效链路长度，得到代码实际求解的方程：

\[
\lambda_iQ_i^{m+1}+a_iF_{b_i}(Q_i^{m+1})
=\lambda_iU_i^{m+1}+a_iF_{b_i}(Q_i^m)+\lambda_iL_{i,t},
\qquad
\lambda_i=\frac{\Delta t}{\Delta x_i^{eff}}.
\]

这里 $U_i^{m+1}$ 是当前子步直接上游格的新出流之和，而不是上一子步的旧上游流量。

### 7.6 拓扑层级求解与传播含义

代码从源头到出口依次处理 `routing_level`。同一层内栅格并行求解；一层的新出流立即累加为下一层的 $U_i^{m+1}$。以三格链路 $A\rightarrow B\rightarrow C$ 为例：

```text
A：用 L_A 和旧 Q_A 求新 Q_A，并把新 Q_A 传给 B
B：用新 Q_A + L_B 和旧 Q_B 求新 Q_B，并把新 Q_B 传给 C
C：用新 Q_B + L_C 和旧 Q_C 求新 Q_C
```

因此，一个子步不等于“水只移动一个栅格”。源头扰动在同一隐式子步中可以影响所有下游层级，传播衰减和时序主要由非线性蓄量–流量关系控制。增加 `d8_substeps_per_day` 是减小 $\Delta t$、提高日内离散精度，不是规定每天移动几个栅格。

### 7.7 两次展开的 Newton 更新

先在

\[
Q_i^{ref}=\frac{Q_i^m+U_i^{m+1}}{2}
\]

处线性化，构造初值

\[
Q_i^{(0)}=
\frac{\lambda_iU_i^{m+1}+a_iF'_{b_i}(Q_i^{ref})Q_i^m+\lambda_iL_{i,t}}
{\lambda_i+a_iF'_{b_i}(Q_i^{ref})}.
\]

定义

\[
C_i=\lambda_iU_i^{m+1}+a_iF_{b_i}(Q_i^m)+\lambda_iL_{i,t},
\]

\[
r(Q)=\lambda_iQ+a_iF_{b_i}(Q)-C_i,
\qquad J(Q)=\lambda_i+a_iF'_{b_i}(Q),
\]

\[
Q_i^{(k+1)}=Q_i^{(k)}-\frac{r(Q_i^{(k)})}{J(Q_i^{(k)})}.
\]

当前实现固定展开两次 Newton 更新。若候选值为负，则用前一非负迭代值的一半代替；若 $C_i\le0$，最终出流置零。固定次数展开使求解过程保留在 PyTorch 自动微分图中，但它不是基于残差容限的完全收敛迭代。

### 7.8 日流量、状态与汇流水量平衡

站点日流量取当天所有子步末流量的算术平均：

\[
\overline Q_{g,t}=\frac1M\sum_{m=1}^{M}Q_{g,t}^{m}.
\]

当前命令行默认 $M=1$，即一次 86400 s 的隐式步，输出为日末流量。可选值为 1、2、4、8、24、48 或 96。气象和产流仍为日尺度，增加子步只是细化汇流数值积分，并不会创造真实的日内降雨过程。

显式汇流状态只有每个有效栅格的 $Q_i$。链路蓄量 $S_i$ 由当前 $Q_i,a_i,b_i$ 重构，不作为独立状态保存。因此优化器改变 $a,b$ 后，即使跨窗口携带的 $Q$ 相同，其隐含蓄量也会随新参数发生变化。

完整流域的汇流水量残差为

\[
\varepsilon^{route}=V_{local}+S_{initial}-V_{outlet}-S_{final}.
\]

内部站上游区也计算相同形式的诊断，但内部站取样不会从下游传播中扣除水量。

### 7.9 对汇流模型性质的准确界定

当前实现可称为“运动波启发的全栅格非线性蓄量汇流”或“可微分 D8 动态汇流”。为避免论文中过度声明，应明确它：

- 是基于 D8 图的逐栅格质量守恒与非线性蓄量–出流关系；
- 有坡面/河道分类型参数场；
- 不是 Saint-Venant 方程的二维水动力求解；
- 不是两套独立的坡面和河道 PDE；
- 不是非河道格到河道格的瞬时聚合；
- 不是每子步固定平移一个栅格；
- 不对 $Q_0,Q_1,Q_2$ 分别设置不同汇流参数。

## 8. 多站点监督损失与参数更新

### 8.1 面积归一化

为避免大控制面积站点仅因体积流量大而主导优化，模拟和观测流量均按测站的固定 D8 上游面积 $A_g^{\uparrow}$ 转换为径流深：

\[
q_{g,t}=Q_{g,t}\frac{86400}{1000A_g^{\uparrow}}
\quad [\mathrm{mm\,d^{-1}}].
\]

### 8.2 原尺度与变换尺度组合 RMSE

对每个站点，仅使用观测有限且非负、模拟有限的日期集合 $\Omega_g$：

\[
RMSE_g^{raw}=\sqrt{\frac1{|\Omega_g|}\sum_{t\in\Omega_g}
(q_{g,t}^{sim}-q_{g,t}^{obs})^2}.
\]

定义低流量增强变换

\[
\phi(q)=\log_{10}(\sqrt{q+10^{-6}}+0.1),
\]

\[
RMSE_g^{tr}=\sqrt{\frac1{|\Omega_g|}\sum_{t\in\Omega_g}
[\phi(q_{g,t}^{sim})-\phi(q_{g,t}^{obs})]^2}.
\]

站点损失和总损失为

\[
\mathcal L_g=0.75RMSE_g^{raw}+0.25RMSE_g^{tr},
\qquad
\mathcal L=\frac1{G_{valid}}\sum_{g\in G_{valid}}\mathcal L_g.
\]

各有效站点等权。原尺度项对洪峰误差更敏感，变换尺度项增加中低流量的影响。缺测和负观测被屏蔽，不插值。NSE、KGE、洪水事件指标只用于评价，不参与优化。

### 8.3 端到端梯度路径

\[
\mathcal L\rightarrow Q_g\rightarrow \text{D8 隐式汇流}
\rightarrow (Q_0+Q_1+Q_2)\rightarrow \text{HBV92 状态方程}
\rightarrow \boldsymbol\theta_i\rightarrow h_\psi.
\]

同一损失还直接更新 D8 汇流的截距和特征权重。因此，网络参数、HBV92 空间参数场和坡面/河道汇流参数是联合率定的，而不是先独立拟合神经网络再离线率定汇流。

若以 $\psi$ 表示时序编码器权重、$\omega$ 表示 HBV92 参数头权重、$\varphi$ 表示 D8 区域化系数，则训练求解

\[
(\psi^*,\omega^*,\varphi^*)=
\arg\min_{\psi,\omega,\varphi}\mathcal L,
\]

优化器另外执行 AdamW 的解耦权重衰减，当前系数为 $10^{-5}$；它不应被等同表述为经典 Adam 中直接加入损失的 L2 惩罚项。HBV 状态和 D8 流量状态不是待优化的自由参数，而是由历史强迫和状态方程顺序推进得到。

## 9. 可微分设计的范围与边界

### 9.1 保留自动微分的部分

- 三种参数编码器和共享 HBV92 参数头；
- sigmoid 参数边界映射；
- HBV92 中的加减乘除、幂、`min/max/clamp` 等分段连续运算；
- 产流深–体积流量换算；
- 坡面/河道 $a,b$ 区域化；
- 非线性蓄量函数及固定两次展开的 Newton 更新；
- 从所有监督站点损失回传至上述可训练量的路径。

### 9.2 固定且不可学习的部分

- 流域掩膜和边界栅格面积比例；
- 填洼后的 D8 下游索引、链路距离、拓扑层级；
- 河道掩膜和 Strahler 等级；
- 测站到栅格的映射及测站上游掩膜；
- 训练期、测试期与气象数据本身。

### 9.3 梯度上的非光滑点和限制

1. 雨雪划分中的 $T\ge TT$ 为硬布尔判断，不能通过比较操作向 `tt` 提供常规梯度；`tt` 仍可能通过融雪和再冻结连续公式获得部分梯度。
2. `min`、`max` 和 `clamp` 是分段可微的；在饱和区间梯度可能为零，在折点处采用自动微分框架的分段导数。
3. sigmoid 物理边界可防止不合理参数，但原始输出绝对值过大时可能进入饱和区，导致梯度变小。代码输出参数接近上下界的比例用于诊断。
4. Newton 求解只展开两次，负值保护包含条件分支；模型可反向传播，但并不意味着每个子步都达到任意精度的非线性收敛。
5. 窗口边界处状态被 `detach`。水文状态连续，但梯度不跨越训练窗口，属于截断反向传播。

## 10. 训练、预热、状态传递与测试

### 10.1 时间窗口

训练使用严格顺序、互不重叠的固定长度窗口，`batch_size=1` 且 `shuffle=False`。第一个目标窗口从 $t_{train,start}+N_{spinup}$ 开始，当前默认预热 365 d、训练窗口 30 d。训练期尾部不足一个完整窗口的日期被丢弃。测试窗口连续覆盖整个测试期，最后一个窗口可以短于标准窗口。按当前默认日期，第一个有监督训练目标日为 2011-01-01；2010 年既属于参数编码器的训练期气候背景，也用于建立水文初态，但不进入监督损失。

命令行结束日期按“包含该日”解释，进入模型后转换为右端不含日期。例如默认 `--train_end 2017-12-31` 在内部表示 `2018-01-01` 之前的日期。

### 10.2 每轮训练的状态初始化

每个 epoch 开始时，从五个 HBV92 初始库容均为 $10^{-3}$ mm、D8 流量状态为 0 出发，使用历史气象进行一次无梯度预热，推进到第一个训练目标日。预热不使用流量观测、不更新权重，也不使用目标期未来强迫。

随后每个训练窗口接收上一个窗口的最终 HBV92 和 D8 状态。状态在窗口边界被复制并从计算图分离：

```text
水文记忆：连续跨窗口
梯度记忆：仅保留当前窗口
```

每个新 epoch 都使用该轮开始时的最新模型权重重新预热，避免沿用旧权重生成的初始状态。

### 10.3 测试状态

测试前使用固定检查点和连续历史气象，无梯度推进至测试首日。状态初始化起点取训练起点与“测试起点减预热天数”二者中更早的日期；按当前默认设置，实际使用 2010-01-01 至 2017-12-31 的全部气象连续推进到 2018-01-01，而不只使用测试前 365 d。测试窗口之间继续携带状态。测试预热不读取流量观测，测试流量也不参与权重选择或更新。

### 10.4 优化器与检查点

| 设置 | 当前值 |
|---|---:|
| 优化器 | AdamW |
| 初始学习率 | 命令行默认 $10^{-3}$ |
| weight decay | $10^{-5}$ |
| 全局梯度裁剪阈值 | 1.0 |
| 学习率调度器 | ReduceLROnPlateau |
| 监控量 | epoch `train_loss` |
| 衰减因子 | 0.5 |
| patience | 1 |
| 相对改进阈值 | $10^{-3}$ |
| 最低学习率 | $\max(0.05\,lr_0,10^{-6})$ |

模型没有验证集和基于验证指标的 early stopping。正式训练结束后使用预先规定 epoch 的 `last.ckpt`；测试指标不参与检查点选择。论文中应写成“固定训练轮数后采用最终检查点”，不能写成“选择验证集最优模型”。

当前检查点结构标识为 `grid_hbv92_neural_parameterizer_d8_hillslope_channel_v10`。检查点保存参数背景身份、HBV 参数边界、编码器配置、损失定义、坡面/河道汇流结构及状态初始化约定；不兼容的旧结构会被拒绝加载。

## 11. 独立伪代码

### 11.1 算法 1：完整训练与评价流程

```text
输入：流域边界、DEM、站点位置与流量、逐日 P/T/PET、训练期、测试期
输出：最终检查点、训练/测试流量、参数场、过程诊断和性能指标

1  在投影网格上裁剪 DEM，并计算边界栅格面积比例
2  以指定出口为约束执行 priority-flood 水文校正
3  构造唯一 D8 下游关系、链路长度、坡度、累计面积和拓扑层级
4  按累计面积阈值建立河道掩膜，将测站映射到 D8 河道格
5  从训练期 P/T/PET 构造固定的标准化气候背景 X
6  FOR epoch = 1 ... E DO
7      用当前权重从历史起点无梯度预热至第一个训练目标日
8      FOR 训练窗口（严格按日期顺序）DO
9          用共享编码器根据 X 和地形生成 12 个 HBV92 参数场
10         从上一窗口状态逐日运行栅格 HBV92，得到 Q0、Q1、Q2
11         将 Q0+Q1+Q2 按实际栅格面积转换为局部体积流量
12         沿全栅格 D8 图隐式汇流，提取所有监督站流量
13         计算多站点等权组合 RMSE
14         反向传播并联合更新编码器、参数头和 D8 区域化系数
15         将窗口末状态 detach 后传给下一窗口
16     END FOR
17 END FOR
18 保存最终 last.ckpt
19 固定检查点，连续回放训练目标期并计算训练指标
20 用历史气象预热至测试首日，连续模拟测试期并计算测试指标
```

### 11.2 算法 2：逐栅格 HBV92 参数场生成

```text
输入：训练期标准化气候背景 X[L,3,H,W]，地形 S[4,H,W]，流域掩膜
输出：12 个静态 HBV92 参数场

1  提取所有有效栅格的 X_i[L,3] 和 S_i[4]
2  按最多 256 个有效栅格分块，以控制显存
3  FOR 每个栅格分块 DO
4      用所选 BiGRU / TCN / Patch Transformer 编码多年气候背景
5      对编码序列计算时间均值与总体标准差
6      拼接静态地形，经过共享两层 MLP 得到 12 个原始值 r_i
7  END FOR
8  恢复为 [12,H,W] 参数网格
9  对每个参数 p 应用 θ_p = lower_p + (upper_p-lower_p) sigmoid(r_p)
10 返回空间异质、时间不变的参数场
```

### 11.3 算法 3：一个栅格的单日 HBV92 产流

```text
输入：当日 P、T、PET；前一日 SP、MW、SM、UZ、LZ；12 个 HBV92 参数
输出：Q0、Q1、Q2；更新后的五个状态

1  按 T 与 TT 的硬阈值把 P 划分为雨和雪
2  将雪加入 SP；按度日公式计算受 SP 限制的融雪量
3  将融雪加入 MW；计算受 MW 限制的再冻结量
4  超过 CWH×SP 的液态水释放到土壤
5  按 (SM/FC)^BETA 计算湿润度和响应库补给
6  超出 FC 的水作为容量超额量加入上层响应库
7  用 LP×FC 控制潜在蒸散转化为实际蒸散
8  从 UZ 先计算 PERC，再计算阈值快速径流 Q0 和慢速径流 Q1
9  将 PERC 加入 LZ，并计算基流 Q2
10 检查旧蓄量 + P - AET - Q0 - Q1 - Q2 - 新蓄量
```

### 11.4 算法 4：一个 D8 汇流子步

```text
输入：旧流量 Q_old[N]，局部源 L[N]，D8 图，参数 a[N]、b[N]
输出：新流量 Q_new[N]

1  incoming[:] = 0
2  FOR routing_level 从上游到下游 DO
3      并行读取该层各格的 U = incoming、Q_old、L、a、b、Δx
4      在 Q_ref = 0.5(Q_old+U) 处计算线性化初值
5      计算隐式守恒方程右端 C
6      重复两次：
7          计算残差 r 和 Jacobian J
8          candidate = Q - r/J
9          若 candidate < 0，则用 0.5Q 代替，否则接受 candidate
10     若 C <= 0，则 Q_new = 0
11     将该层 Q_new 累加至各自唯一 D8 下游格的 incoming
12 END FOR
13 返回 Q_new
```

### 11.5 算法 5：连续状态训练

```text
1  每个 epoch 开始时，用当前权重无梯度预热得到 state_0
2  FOR 按时间顺序排列的窗口 w DO
3      output_w, state_end = Model(forcing_w, state_start)
4      loss_w = MultiGaugeLoss(output_w, observation_w)
5      对 loss_w 反向传播并更新参数
6      state_start = clone(detach(state_end))
7  END FOR

说明：第 6 步保持物理状态连续，但阻断跨窗口梯度。
```

## 12. 数据泄漏与信息边界

- HBV 参数编码器只使用训练期气象背景和静态地形；
- 测试期 P/T/PET 仅作为测试期物理模拟的逐日外部强迫；
- 测试流量只用于最终评价，不参与参数生成、梯度更新或检查点选择；
- 历史预热只使用气象强迫，不同化流量观测；
- 训练和测试采用预先声明的时间边界。

因此，在上述约定得到遵守且数据文件时间标签正确的前提下，BiGRU 的双向编码和 Patch Transformer 的全局注意力不会引入测试期信息泄漏，因为二者只处理固定训练期背景。若未来把参数背景扩展到完整数据期，则必须重新审查这一结论。

## 13. 诊断量、评价与输出

模型保存以下核心过程诊断：

- 流域平均 P、T、PET、雨、雪、融雪、再冻结、入渗、补给、AET、渗漏、`Q0/Q1/Q2`；
- 五个 HBV92 蓄水状态及 HBV 水量平衡残差；
- D8 初末蓄量、局部入流体积、出口体积和汇流残差；
- 每个测站上游区的 P、AET、补给、产流分量、汇流蓄量和水量平衡；
- 12 个 HBV 参数与 $a,b$ 的均值、分位数和接近边界比例；
- 编码器、参数头、各 HBV 输出及汇流参数的梯度范数和裁剪比例。

逐日性能至少包含 NSE、KGE、RMSE 等。洪水事件由观测序列定义，训练期 Q95 为洪水阈值、Q75 为消退边界；事件选择不读取模拟序列。训练连续回放和测试期生成相同类型的事件评价图：

- `flood_event_nse_heatmap.jpg`；
- `flood_event_kge_heatmap.jpg`；
- `flood_peak_relative_error_heatmap.jpg`；
- `flood_peak_timing_error_heatmap.jpg`；
- `flood_peak_scatter.jpg`；
- `flood_event_station_summary.jpg`；
- 每个事件的 `E_YYYYMMDD_hydrographs.jpg`；
- `by_station/` 下的逐站事件图；
- `top5_by_station/` 下各站观测峰值排名前 5 的事件图。

这些评价产品均在模拟完成后生成，不参与反向传播。

## 15. 论文 Methods 建议组织

论文正文可按以下顺序展开：

1. **总体框架**：说明神经网络负责空间参数区域化，HBV92 和 D8 模块负责显式水文过程。
2. **输入与网格**：说明 P/T/PET、DEM、实际栅格面积、D8 拓扑和测站映射。
3. **神经参数区域化**：给出训练期背景、共享编码器、12 参数边界映射和静态参数假设。
4. **分布式 HBV92 产流**：给出雪、土壤、蒸散和响应库方程。
5. **可微分 D8 汇流**：重点给出坡面/河道参数场、蓄量函数、隐式守恒方程和 Newton 展开。
6. **多站点联合训练**：给出面积归一化组合损失、连续状态传递和优化设置。
7. **评价与诊断**：说明 NSE/KGE、洪水事件性能、水量平衡与参数边界诊断。

可用于正文的高度概括表述如下：

> 我们构建了一个神经参数化的可微分分布式水文模型。共享时序编码器根据各栅格训练期多年降水、气温和潜在蒸散背景及静态地形属性，生成具有物理边界的 12 个空间异质 HBV92 参数场。HBV92 在日尺度逐栅格更新积雪、土壤水和上下层响应库，并将快速径流、壤中流和基流之和按栅格实际面积转换为局部体积流量。局地产流随后在完整有效栅格组成的 D8 有向图上动态传播。汇流模块在统一守恒方程内为坡面格和河道格使用不同的、由累计面积、坡度、高程和河道类别区域化的非线性蓄量–出流参数，并以固定展开的隐式 Newton 更新保持端到端自动微分。模型由内部站与出口站的面积归一化组合流量损失联合率定，测试期流量不参与参数学习或检查点选择。

在论文中还应主动说明以下限制：当前气象和产流为日尺度；汇流子步不代表真实日内降雨；雨雪分界为硬阈值；三种径流分量共用一套空间汇流；河道几何没有显式宽度和糙率；Newton 更新固定为两次；当前实验没有独立验证集。

## 17. 运行示例

默认 Pascagoula、BiGRU 参数编码器：

```bash
python disthybridcore/experments/run.py --mode all
```


只准备数据：

```bash
python disthybridcore/experments/run.py --mode prepare
```

当前 `all` 模式依次完成数据准备、训练、固定检查点训练期连续回放、测试和站点分析。输出位于 `outputs/hybrid/<basin>_<timestamp>/`。
